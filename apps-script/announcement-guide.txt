Whatever you write in this cell appears at the top of the check-in page for every student, after they enter today's code.

Write \n where you want a line break, and \\ if you need an actual backslash. Two line breaks in a row start a new paragraph. Anything the system doesn't recognise is left on the page exactly as you typed it, so a typo shows up rather than disappearing.

For formatting, wrap text in **two asterisks** for bold, *one asterisk* for italic, __two underscores__ for underline, and ~~two tildes~~ for strikethrough. Links are [the words you want shown](https://the-address). Start a line with # for a heading or > for a quote, wrap text in `backticks` for code, and write ![description](https://image-address) for a picture. Bold, italics and links you apply with the toolbar work too. An asterisk with no partner, as in 2*3, prints as written; to print a marker that would otherwise format something, put a backslash in front of it, like \*.

You can also ask students a question. Put a tag like this where the question should appear, all on one line: <input type="number" data-label="Your guess" min="0" max="6767" data-col="K" required>. The data-label is the question students see, and data-col is the column their answer is written to, in their own row. Use column G or later, since A to F belong to check-in. Add required if they must answer; those questions get a red star. Add data-only="123456789|987654321" to show a question only to those student IDs. Each question needs its own column.

The types are text, textarea (a bigger box), number, color, radio, select, rating and checkbox. A text or textarea question can take minlength and maxlength. A number question can take min and max, and step: whole numbers only unless you write step="any" for decimals or something like step="0.5". The range is shown only to a student whose number falls outside it. A color question writes the colour's code and shades the student's cell in it.

Radio buttons and dropdowns list their choices in options, separated by commas, like options="'Yes', 'No', *'Maybe', Other". The star marks the choice that starts selected. Quotes are optional, but use them when a choice contains a comma, and put a backslash before a quote or comma inside one, as in 'Don\'t know'. On a radio question, Other written without quotes adds a box where students type their own answer, and what they type is saved. 'Other' in quotes is just an ordinary choice. Use type="select" for a dropdown when there are many choices.

A rating is a row of numbered boxes, 1 to 5 unless you set min and max, up to 11 boxes. Write data-low="Rough" and data-high="Great" to label the two ends. For checkboxes, give each box its own column: <input type="checkbox" data-label="Which days can you come?" option-k="Wednesday" option-l="Thursday" option-m="Friday" option-m-checked>. The checked part ticks Friday to start, and each column fills with real checkboxes. For a single box, use data-col and data-label instead, like <input type="checkbox" data-label="I can stay for the photo" data-col="N">.

If a tag has a mistake, the page still does its best and this cell turns red. MATHCOUNTS > Check code and announcement explains what is wrong, including two questions sharing a column or a data-only ID that isn't on the roster. MATHCOUNTS > Clear announcement answers empties the question columns for a new day; New day does not touch them. A student who checks in again replaces their answers, and the old ones are kept in that cell's note. To show a tag as text instead of a question, write \<input.
